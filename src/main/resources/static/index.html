用之前
  • 先开预演模式：走完整流程但不真投，记录显示"预演"。确认筛选符合预期再关。
  • 一次只跑一个平台：四个平台共用同一个 Chrome 窗口，同时启动会被全局运行锁拦下。
  • 投递时窗口不要最小化：页面在后台时部分站点会暂停渲染，导致点击落空。
  • 智联只采得到职位名、经验、薪资：学历/HR/行业/规模/JD 这几组打分规则在智联上不会命中。
