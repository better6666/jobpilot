用之前
  • 先开预演模式：走完整流程但不真投，记录显示"预演"。确认筛选符合预期再关。
  • 一次只跑一个平台：五个平台共用同一个 Chrome 窗口，同时启动会被全局运行锁拦下。
  • 投递时窗口不要最小化：页面在后台时部分站点会暂停渲染，导致点击落空。
  • 智联采得到学历/行业/规模/JD：这些都从详情面板读，但 HR 标识和 HR 活跃度采不到，所以"过滤不活跃 HR"在智联上不生效。
  • 想让话术不像群发：去"AI 话术"页接一个 OpenAI 兼容接口（官方或中转站都行），填好求职者背景即可。
