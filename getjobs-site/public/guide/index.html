下载安装

  1. 在 Windows 10 或 11（64 位）电脑上打开软件下载页，点蓝色的「下载 Windows 轻量版」。轻量版使用已安装的 Edge 或 Chrome。
  2. 下载后右键 ZIP 文件，选「全部解压缩」。在解压后的文件夹里双击 JobPilot.exe，等待工作台打开。

主链接暂时打不开时，可使用页面里的「GitHub 备用下载」。需要随包浏览器时，选 Windows 完整版。

激活卡密

在软件左侧点「卡密管理」，粘贴购买后收到的卡密，点「激活卡密」。看到「已激活」后回到工作台。

提示「无法连接卡密服务端」怎么办？
  1. 退出 JobPilot。打开解压文件夹里的 app，用记事本打开 JobPilot.cfg。
  2. 找到以 java-options=-Dlicense.api-base= 开头的一行，整行换成下面的内容。 java-options=-Dlicense.api-base=https://jobpilot.better999.dpdns.org
  3. 按 Ctrl + S 保存，重新打开 JobPilot.exe 并激活。

如果提示卡密无效、过期或设备数已满，请联系购买渠道，并提供报错文字。

已装旧版怎么更新

Windows v1.0.23–v1.0.28 如果还在连接旧站，可以按下面的步骤迁移一次。更新会沿用原来的卡密、简历、设置和投递记录。

  1. 退出 JobPilot。在解压目录用记事本打开 app\JobPilot.cfg。
  2. 找到以 java-options=-Dlicense.api-base= 开头的一行，用下面的两行替换。如果文件里已经有 java-options=-Dupdates.manifest-url=，请把它更新为下面的地址，每个配置只保留一行。 java-options=-Dlicense.api-base=https://jobpilot.better999.dpdns.org java-options=-Dupdates.manifest-url=https://cheshi.dpdns.org/updates.json
  3. 保存后打开 JobPilot.exe。看到新版说明后点「更新并重启」。也可以在软件左下角点「检查更新」。

你也可以直接下载新版，解压到新文件夹后打开。v1.0.22 及更早版本请用这个方法升级。

导入简历

打开「简历与画像」，点「导入简历」，选中 PDF、Word 或 TXT 文件。每份最多 10 MB。导入后核对文件名和提取出的文字。

如需在 Boss 直聘或猎聘的聊天中发送附件，在「投递设置」里选中「简历附件」，再勾选「聊天中自动发送所选简历」。

自动发送默认关闭。预演时不会上传附件。需要对方同意的会话会单独提示。

填写条件，启动预演

  1. 在「投递工作台」右上角选 Boss 直聘或猎聘，选城市，每行填一个关键词。第一次可把「每个关键词最多处理」设为 5。
  2. 在「发送话术」选固定话术并填写招呼语。话术里的 {岗位} 会替换为实际岗位名称。
  3. 保持「预演模式」勾选，点「开始投递」。Boss 直聘提示扫码或验证时点「打开浏览器处理」。猎聘按弹出的浏览器登录页提示操作。

话术示例　您好，我对贵公司的{岗位}感兴趣，期待进一步沟通。谢谢！

核对记录，正式投递

  1. 在「投递记录」里检查岗位、公司和原因。「预演」状态表示这条没有实际发送。岗位不合适时，调整条件后再预演。
  2. 确认后取消勾选「预演模式」，再点「开始投递」，正式任务的岗位间隔至少 20 秒。需要中止时点「停止」。
  3. 在「投递记录」查看「已投递」或「失败」等结果。Boss 直聘提示「待核对」时，到平台聊天确认消息是否发出。登录或运行异常可查看「运行日志」。
